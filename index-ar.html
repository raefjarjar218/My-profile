01 — نبذة

هندسة برمجيات تركز على الوضوح والموثوقية والقيمة طويلة المدى.

أساعد الشركات على تحويل المتطلبات إلى منتجات رقمية مستقرة ومبنية بشكل جيد — مصممة للاستمرار، وليس فقط للإطلاق.

02 — الخبرات

التقنيات والتخصصات التي أعمل بها.

مجموعة تقنيات مركزة، تُطبَّق من البداية إلى النهاية — من نمذجة البيانات إلى الواجهة النهائية.

01

تطوير الواجهة الأمامية

واجهات متجاوبة ودقيقة مبنية بـ HTML5 الدلالي و CSS3 الحديث و JavaScript الصافي — سريعة، سهلة الوصول، ومتسقة عبر الأجهزة.

  • HTML5
  • CSS3
  • JavaScript
  • تجاوب
02

تطوير الواجهة الخلفية

تطبيقات خلفية قوية باستخدام PHP وإطار Laravel — واجهات RESTful API، مصادقة، تفويض، وهندسة تطبيقات قابلة للتوسع.

  • PHP
  • Laravel
  • REST API
  • MVC
03

تصميم قواعد البيانات

مخططات MySQL مُنظَّمة، فهرسة فعالة، وتحسين الاستعلامات — مع نماذج Eloquent ORM التي تحافظ على وصول نظيف ومتوقع للبيانات.

  • MySQL
  • Eloquent
  • SQL
  • تحسين
